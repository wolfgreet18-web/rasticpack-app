# ویجت قیمت‌دهی سریع (اندروید)

همه‌ی کد بومی ویجت داخل `install_widget.py` است و لازم نیست چیزی را دستی بنویسید.

## مراحل
1. `hrml28.html` را جای HTML قبلی برنامه بگذارید.
2. `install_widget.py` را در ریشه‌ی پروژه بگذارید (کنار `capacitor.config`).
3. در GitHub Actions، بعد از `npx cap add android` و قبل از Build:
   ```yaml
   - name: Add home-screen widget
     run: |
       npm i @capacitor/app
       python3 install_widget.py
       npx cap sync android
   ```
4. APK جدید را نصب کنید → برنامه ← تنظیمات ← 🧩 ویجت ← فعال.

## ویجت چه می‌کند
- همان فیلدهای تب قیمت: L، W، H، N، لپ، سود، چک، تعداد لایه، نوع ورق، عرض ورق.
- با لمس هر کادر انتخابش می‌کنید و با کیپد عدد می‌زنید (◄ ► بین کادرها).
- نتیجه فوری: چکی، فروش، تخفیف، پایه، مبلغ کل، سود کل، ضایعات کل، مشخصات ورق انتخابی.
- محاسبه با خود توابع تب قیمت انجام می‌شود (برنامه متن توابع را به ویجت می‌دهد)؛ ورق‌ها و قیمت‌ها هنگام خروج از برنامه به ویجت منتقل می‌شوند.
- قابل کوچک/بزرگ کردن است؛ ↗ برنامه را روی تب قیمت باز می‌کند، ↻ همه چیز را پاک می‌کند.
