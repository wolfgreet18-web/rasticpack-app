# ویجت قیمت‌دهی سریع (اندروید)

همه‌ی کد بومی ویجت داخل `install_widget.py` است و لازم نیست چیزی را دستی بنویسید.

## مراحل
1. `hrml28.html` را جای HTML قبلی برنامه بگذارید.
2. `install_widget.py` را در ریشه‌ی پروژه بگذارید (کنار `capacitor.config`).
3. در GitHub Actions، بعد از `npx cap add android` و قبل از Build:
   ```yaml
   - name: Add home-screen widget
     run: |
       npm i @capacitor/app
       python3 install_widget.py
       npx cap sync android
   ```
4. APK جدید را نصب کنید → برنامه ← تنظیمات ← 🧩 ویجت ← فعال.

## ویجت چه می‌کند
- ظاهر و فیلدهای تب قیمت: L، W، H، N، لپ، ۳/۵ لایه، نوع ورق، عرض ورق، سود، چک.
- لمس کادرهای L/W/H/N/سود/چک ← پنجره‌ی کوچک با کیبورد خود گوشی (دکمه‌ی Next بین کادرها).
- دکمه‌های +/− برای سود و چک، گروه‌های دکمه‌ای برای لپ/لایه/ورق/عرض.
- نتیجه: چکی، فروش، تخفیف، پایه، مبلغ کل، سود کل، ضایعات کل، مشخصات ورق و پرت.
- محاسبه با خود توابع تب قیمت انجام می‌شود؛ ورق‌ها و قیمت‌ها هنگام خروج از برنامه به ویجت منتقل می‌شوند.
- قابل کوچک/بزرگ شدن؛ ↗ برنامه را باز می‌کند، ↻ پاک می‌کند.
